# RUN INSTRUCTIONS

First-time build:
```
npm install
```

## TUI Mode

1. In cmd:
```
node chargeTUI.js
```

## GUI Mode

1. In cmd:

```
node chargeGUI.js
```
2. Open http://localhost:3000 in your preferred browser.
