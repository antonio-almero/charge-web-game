# RUN INSTRUCTIONS

TUI Mode:
<br><br>
In cmd:
```
node chargeTUI.js
```
<br>
GUI Mode:
<br><br>

1. In cmd:

```
node chargeGUI.js
```
2. Open http://localhost:3000 in your preferred browser.
